# Product roadmap

Status: Active

This roadmap records the product phases for `narihitos-diary`. Phase 1 is the
only active phase; later phases remain unplanned until their goals are defined.

| Phase | Title | Status | Goal | Plan |
|---|---|---|---|---|
| 1 | macOS TUI MVP | Active | Turn Markdown source notes from a mounted iCloud directory into a finished diary entry and publish its body to a daily section in a Notion month page. | [Phase 1](phase-1/phase-1.md) |
| 2 | TBD | Planned | — | Not yet created |
| 3 | TBD | Planned | — | Not yet created |
| 4 | TBD | Planned | — | Not yet created |
| 5 | Standalone iOS app | Planned | Deliver `narihitos-diary` as a standalone iOS app. | Not yet created |

## Noted for later phases

- Phase 2 will include an MCP server: the Control API Server's `/mcp` endpoint
  for MCP clients. An MCP CLI is not part of this note. Agent clients (Codex,
  Claude Code) may read the allowed diary data classes and write draft
  proposals; confirming, approving, and publishing stay human-only. Phase 2
  stays unplanned until its goal is defined.
